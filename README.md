## 🧠 Sobre mí

Me gusta meterme en la capa donde las cosas realmente se ejecutan: motores de datos en Rust + Python, apps de escritorio que orquestan procesos con IA 100% local, y programas on-chain en Solana. Entre proyecto y proyecto, también construyo apps Flutter, sistemas web con Laravel/Express y hasta minijuegos educativos.

- 🔭 Ahora mismo: **Hachikage**, una app de escritorio que automatiza Git/GitHub desde un chat con modelos locales vía Ollama.
- 🪽 En paralelo: **Denki Pipeline Designer + Tsubasa**, un editor visual de pipelines de datos/ML que compila a un motor Rust/Python sobre Polars.
- 🦀 Aprendiendo **Rust** a fondo — ya lo uso en producción propia (`series_ast`, el programa de Solana/Anchor).
- 💬 Pregúntame de: arquitecturas Electron (main/preload/renderer), AST/DAGs, o cómo enrutar tareas entre modelos locales.
